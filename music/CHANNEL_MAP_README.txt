STANDARD CHANNEL LAYOUT (all MIDI files in this project)
==========================================================
Ch 1  (MIDI 0) : Lead / main melody
Ch 2  (MIDI 1) : Harmony (stabs / pad / piano left hand)
Ch 3  (MIDI 2) : Bass (or drone)
Ch 4  (MIDI 3) : Motion (arpeggio / harp / handpan roll)
Ch 5  (MIDI 4) : Accents (shimmer / bells / echo)
Ch 10 (MIDI 9) : Percussion (all drum/noise tracks; GM drum channel)

Note: some files have two percussion tracks (e.g. hi-hat and kick/snare).
They share Ch 10 but remain separate named tracks, so trackers can map
them to separate voices. Files without a given role leave that channel empty.
